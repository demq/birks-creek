# Birks Creek — Website & Deployment Plan

> *"Parkside's newest natural waterway. Est. 2024. Source: a building site."*

A tongue-in-cheek, animated one-page site documenting the constant groundwater
discharge from the new builds at the Fullarton Rd end of Birks St, which
flows down Birks St carrying debris and pools at the corner of **Myra St**.

---

## 1. Goals

- Make the problem **impossible to ignore and easy to share**: one memorable URL, a
  link people can send to neighbours, the council and local media.
- Use **real evidence** (dated photos, satellite view of the flow path) as the base,
  styled with filters and canvas animation so it's fun to look at.
- Keep the sarcasm aimed at **the situation**, with every factual claim provable.
- **$0 hosting.** Paying for a domain is optional (see §5).

## 2. Tone & content guardrails

Satire is fine, but naming addresses makes this worth being careful about
(Australian defamation law applies):

- State **facts** plainly (dates, photos, what flows where); put the jokes in the
  framing ("Birks Creek Visitor Centre", "wildlife sightings: 3 leaves, 1 chip packet").
- Don't name or speculate about owners, builders or individuals. No faces, no
  number plates. Blur them if they show up in new photos.
- Don't claim breaches of law; say *"we'd like the council/EPA to check whether…"*.
- Include a serious "What should happen / who to contact" section so the page has
  a constructive purpose.
- Check photos for GPS EXIF before publishing (the current two have none).

## 3. Page concept (single scrolling page)

| # | Section | What it shows | Tech |
|---|---------|---------------|------|
| 1 | **Hero — "Welcome to Birks Creek"** | Animated water trickling across the title; live counter "Flowing for **N** days" (since first photo, 19 Feb 2024) | Canvas 2D particle flow |
| 2 | **The Source** | The two addresses as "headwaters", in a mock National Park info board | CSS + SVG "park sign" styling |
| 3 | **The Journey** | Satellite view of Birks St; as you scroll, an animated blue line traces the water from the source down to Myra St | Map tiles + canvas/SVG path overlay, scroll-driven |
| 4 | **Lake Myra** | The puddle photos with a **WebGL ripple shader** on the water area; mouse/touch makes ripples | WebGL fragment shader (or Canvas fallback) |
| 5 | **Field Guide** | Each photo in a different filter: "nature documentary" (warm vintage), "tourism brochure" (over-saturated), "crime scene" (high-contrast + tape overlay), "Visit Birks Creek" postcard | CSS filters + canvas duotone |
| 6 | **Evidence Log** | Dated timeline of every photo: date, time, location, short factual note | Data from a JSON file — adding a photo = adding one entry |
| 7 | **What should happen** | Plain, serious summary + who to contact | Static text |
| 8 | Footer | "Not affiliated with any tourism authority." Image credits / map attribution | — |

Extras if time permits: ambient water sound (off by default), "Adopt-a-Leaf" button,
dark "night at the creek" mode, social preview image (Open Graph) for nice link
previews when shared.

## 4. Tech stack

- **Vite + vanilla TypeScript** — no framework needed for one animated page; fast
  build, outputs plain static files.
- **Canvas 2D** for particle water; **WebGL** (hand-written shader, ~60 lines) for
  the ripples. No heavy 3D library.
- **MapLibre GL JS** or **Leaflet** for the satellite view, with a custom overlay
  for the flow path.
- **Images**: originals in `photos/` (kept out of the build); resized/compressed
  WebP + JPEG fallbacks generated by a small `sharp` script into `public/img/`.
- **Accessibility**: respect `prefers-reduced-motion` (animations become static),
  alt text on every photo, readable without JavaScript.

### Satellite imagery — licensing matters

Screenshotting Google Maps/Earth isn't allowed by their terms. Options, best first:

1. **Esri World Imagery tiles** in Leaflet/MapLibre with on-map attribution —
   free for low-traffic non-commercial use (confirm current terms when building).
2. **Mapbox Satellite** — free tier (50k map loads/month), needs a public token.
3. **SA Government aerial imagery** (Location SA / data.sa.gov.au) — check the
   licence (often CC-BY) for a static, filterable image of the block.

A static image (option 3, or a styled crop) is best for the canvas effects; a live
map (option 1/2) is best for the scroll-driven journey. We can do both.

## 5. Hosting & domain

### Hosting: Cloudflare Pages (free)

- Unlimited bandwidth, global CDN, HTTPS, 500 builds/month — far more than needed.
- Gives a free subdomain: **`birkscreek.pages.dev`** (fallback:
  `birks-creek.pages.dev`). The project name decides the subdomain; whoever
  claims it first gets it.

### Domain options

There's no reliable *free* `.com`-style domain any more (Freenom is gone).

| Option | Example | Cost | Notes |
|--------|---------|------|-------|
| **A. Pages subdomain** (recommended to start) | `birkscreek.pages.dev` | Free | Live in minutes, no admin |
| B. Free community domain | `birkscreek.eu.org` | Free | Manual approval, can take weeks; point DNS at Cloudflare |
| C. Cheap real domain via Cloudflare Registrar | `birkscreek.com` | ~US$10/yr, at cost | Most memorable; add as custom domain in Pages |
| D. Australian domain | `birkscreek.au` / `.com.au` | ~A$15–25/yr | `.com.au` needs an ABN; `.au` needs an Australian presence. Not sold by Cloudflare Registrar |

**Recommendation:** launch on `birkscreek.pages.dev`; add `birkscreek.com` later if
the site gets attention (the `pages.dev` URL keeps working either way).
Availability of these names couldn't be checked from here — verify when signing up.

### Deployment flow

1. `git init`, push to a GitHub repo (`birks-creek`, public or private).
2. Cloudflare dashboard → Workers & Pages → Create → Pages → **Connect to Git**.
   - Project name: `birkscreek`
   - Framework preset: Vite · Build command: `npm run build` · Output: `dist`
3. Every push to `main` auto-deploys; every other branch/PR gets its own preview URL.
4. Alternative without GitHub: `npx wrangler pages deploy dist --project-name birkscreek`.
5. Optional later: custom domain (option C), Cloudflare Web Analytics (free, no
   cookies) to see visit counts.
